# **App Name**: Immersive Escapes

## Core Features:

- Ambiance Packs: Display a curated grid-based list of relaxation ambiance packs (Fireplace, Rain, Aquarium). Content is driven by JSON configuration.
- Immersive Player View: Enable a fullscreen player view that renders the selected ambiance. Handles both video and animated Canvas placeholders.
- Animated Canvas Placeholders: Dynamically render Canvas-based animations (Fireplace, Rain, Aquarium) as fallback when video assets are unavailable.
- Sleep Timer: Set a timer to automatically stop playback after a specified duration (15, 30, 60, 120 minutes).
- IAP Integration: Enable premium content via Amazon IAP. 3 free and 9 purchase. Unlocked via 'premium_all' entitlement.
- AI-Driven Soundscapes: Integrate a generative AI tool to subtly modify audio loops based on user activity or timer status, creating evolving soundscapes. The LLM will use reasoning to decide when or if to incorporate some piece of information in its output; this is a tool.
- TV-Optimized Navigation: Implement focus management for seamless D-Pad/Gamepad/Keyboard navigation, including focus ring effects.

## Style Guidelines:

- Background color: Dark charcoal gray (#0B0B0E) for a calm, immersive feel.
- Primary color: Soft lavender (#B284BE) to bring relaxation.
- Accent color: Muted cyan (#70A1AF) for interactive elements and highlights.
- Font: 'Literata', a transitional serif, for a readable, relaxing and elegant style. The classification of Literata is serif.
